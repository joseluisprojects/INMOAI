# InmoAI

Sistema de automatización para captación inmobiliaria mediante inteligencia artificial.

## Objetivo

Automatizar el proceso de captación de propietarios:

- Buscar anuncios de particulares.
- Analizar oportunidades.
- Contactar automáticamente.
- Gestionar conversaciones.
- Priorizar leads para el agente inmobiliario.

Proyecto desarrollado por José Luis.
